VSCodroid Privacy Policy

Last updated: August 2026

Summary

VSCodroid does not collect, transmit, or store any personal data. Everything runs locally on your device.

Data Collection

VSCodroid collects no data. Specifically:

  • No analytics, and no telemetry sent. The editor's own telemetry code is still in the build; it is switched off in the product configuration at build time and again at every start, and the build carries no telemetry endpoint for it to report to — disabled and unaddressed, rather than deleted
  • No crash reporting to external servers
  • No usage tracking
  • No advertising SDKs
  • No third-party SDKs that collect data

On-Device Processing

All code editing, terminal sessions, file operations, and extension hosting happen entirely on your device. The VS Code Server runs locally on localhost and is never exposed to the network.

Network Requests

VSCodroid makes network requests only when you explicitly initiate them:

  • Extension marketplace — When you search for or install extensions, requests go to open-vsx.org (the Open VSX registry).
  • Git operations — When you push, pull, or clone repositories, requests go to the Git remote you configured (e.g., GitHub, GitLab).
  • npm packages — When you run npm install, requests go to the npm registry. The same applies to other package managers you run yourself, such as pip.
  • Signing in to a service from the editor — If an extension asks you to sign in (to GitHub, for example), VSCodroid hands the authorisation URL to your device's browser and the sign-in happens there, not inside the app. The app receives back only the opaque value the editor itself issued, and passes it to the editor page unread — it does not parse, store or transmit your credentials. Tokens the editor keeps afterwards are stored locally in the app's private storage.
  • SSH connections — If you use the bundled SSH client, the connection goes directly from your device to the server you name. VSCodroid does not proxy, monitor or log it.
  • Toolchain downloads — Optional language toolchains (Go, Ruby, Java 17) are delivered one of two ways, chosen at runtime from the package that installed the app: Google Play Store asset packs when that package is the Play Store, and otherwise a ZIP downloaded over HTTPS from this project's GitHub Releases — which covers sideloaded APKs, debug builds, adb install, and any install whose source cannot be read.

No data is sent to VSCodroid developers or any third-party analytics service.

Android Backup (on by default)

One directory does leave the device if you have Android backup enabled: ~/.vscodroid/data/Machine, which holds your editor settings — theme, keybindings, preferences. Android uploads it to your Google account, not to us; we never see it.

It is written as an allowlist, so anything not named is excluded. Not backed up: your SSH keys and the local server's connection token, your projects, any folder you opened from device storage, the bundled runtimes and installed toolchains, and the app's own preferences. To switch it off, use Android's control — Settings → Google → Backup, or your device's per-app backup setting. It is Android's switch, not ours.

Local Storage

All data is stored within the app's private sandbox on your device:

  • Source code files and projects
  • Editor settings and extensions
  • SSH keys (stored in ~/.ssh/ within the app sandbox)
  • Terminal history and editor state
  • Copies of folders you open from device storage. When you open a folder through the Android file picker the app does not edit it in place: it copies the folder into its own storage, works on that copy, and writes your changes back to the original. A second copy therefore exists inside the app while that folder is open to you. It never leaves the device and is excluded from backup, but you should know it is made.

Uninstalling VSCodroid removes all this data.

Permissions

  • Internet — Required for the uses listed under Network Requests above, all of them user-initiated. It is the only permission the app declares that reaches the network.
  • Foreground Service — Keeps the local development server running while you code.
  • Notifications — Shows that the server is active (required by Android for foreground services).

Children's Privacy

VSCodroid is a developer tool and is not directed at children under 13. We do not knowingly collect data from anyone, including children.

Changes to This Policy

If this policy changes, the updated version will be posted here with a new date. Since we collect no data, meaningful changes are unlikely.
